# 默认支持 HTTP／HTTPS 管理入口，并显式配置入口限制与代理信任

为支持内网直连和反向代理部署，管理入口默认支持 HTTP 与 HTTPS，不再因非回环监听而强制 HTTPS，也不增加独立的“允许不安全 HTTP”开关。用户已确认此方向；HTTP 会使管理员密码、会话凭据及管理请求缺少传输加密和链路完整性保护，由部署者承担网络安全责任，部署说明与启动警告须明确该风险；身份认证、Origin 与 CSRF 防护不能因此取消，HTTPS 入口的 Cookie 保护不能因同时支持 HTTP 而降级。

管理入口限制默认不配置；部署者显式配置允许的入口后，仅这些入口可用。默认不配置不代表取消身份认证或 CSRF 防护。

普通直连不要求配置受信代理；需要依赖转发头识别浏览器侧入口时，部署者须显式配置受信代理地址或网段。仅信任这些代理提供的外部协议与主机信息，不无条件信任任意客户端提交的转发头；受信代理范围与管理入口允许列表是独立边界。

显式配置管理入口允许列表后，未列出的入口不得访问整个管理面，包括 WebUI、初始化、登录及全部管理 API，而不只是管理写操作。模型调用与 MCP 不受管理入口允许列表影响，继续遵循各自既有认证与访问规则；该应用层限制不替代防火墙对后端端口的网络隔离。

管理入口允许列表与受信代理仅通过部署端启动参数或环境变量配置，重启生效，不增加 WebUI 设置或数据库配置。配置错误导致管理入口不可用时，由部署者修改启动配置并重启恢复。

管理入口限制不等于跨源授权；管理写请求仍须匹配当前请求的外部 Origin，并保留 CSRF 防护。HTTPS 入口校验及 Cookie 安全属性按外部协议执行，即使代理回源使用 HTTP 也不能降级。本决策保留 [ADR-0040](0040-separate-admin-identity-and-revoke-sessions.md) 的管理身份隔离及撤销原则。部署参数、转发头信任和 Cookie 规则见[管理认证设计](../design/admin-auth-bootstrap.md)与中英文 README。
