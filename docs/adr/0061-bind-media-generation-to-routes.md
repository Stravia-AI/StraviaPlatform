# 媒体生成绑定 Route 而非单个 Provider

媒体生成作为高级能力，通过统一的 `generate` 工具按 `type` 与类型专属 `input` 执行，首个支持的类型为图片，首个接入后端为 Codex。管理员按生成类型分别绑定 Route，当前只配置图片生成绑定；未来音频、视频沿各自类型增加绑定，不共用一条能力级 Route。`generate` 根据 `type` 选择管理员绑定，调用方不能通过工具参数自行指定 Route。每个绑定由 Route 的 Target 选择机制选择上游账号，不仿照现有 Codex 搜索将能力固定绑定到一个 OAuth Provider。

媒体生成沿用 [ADR-0016](0016-gate-advanced-capabilities-and-separate-transparent-injection.md) 的平台总开关与透明注入分离规则：总开关开启后，所有有效 API Key 均可显式调用；MCP 另受现有 MCP 开关约束；平台总开关关闭时所有入口都不能执行。API Key 的透明注入增加独立的“媒体生成”可选项，默认不勾选，包括已有 Key；勾选只允许自动向模型暴露 `generate`，不充当显式调用或 MCP 的授权条件。该选择使普通对话可按需生成媒体，同时避免升级后自动扩大已有 Key 的工具暴露范围。

管理面在“高级功能”下新增“媒体生成”配置页，本期仅提供能力总开关、图片生成 Route 选择、配置校验及当前支持类型的说明，不增加手动试生成、参考图上传或图片预览工作区。实际生成通过客户端工具调用、透明注入或 MCP 执行，避免为管理员身份另建生成与 Artifact 归属路径。

选择 Route 是为了复用多账号调度，而不是在媒体生成中维护另一套账号列表。媒体生成要求绑定符合该用途的专用 Route：所有已启用 Target 都必须满足当前生成类型的适配器接入要求；不能绑定混合 Route 后静默过滤不兼容 Target。绑定时及每次执行前均校验，已绑定 Route 后续混入不兼容的已启用 Target 时，生成明确失败；已禁用 Target 不参与此校验。此处的专用约束不新增 Route 类型，也不表示禁止该 Route 被普通推理引用。

首个版本仅支持 Codex 图片生成，普通推理可用性和模型目录声明的图片输出能力不能替代适配器资格校验。选择专用 Route 增加了独立维护成本，但使管理员看到的已启用 Target 集合与媒体生成使用的候选集合一致。

Codex 接入参考 OMP 的托管生图链路：Target 配置支持托管图片工具的 GPT 对话模型，复用所选 Provider 的 Codex 认证与连接设置，请求 Responses 并以 `tool_choice` 强制使用 `image_generation`。有参考图时请求编辑，无参考图时请求生成；消费流式响应并提取图片结果后收存为 Artifact。不运行本地 Codex CLI，也不采用直接调用 `images/generations` 或 `images/edits` 的独立图片接口。具体支持的模型及尺寸映射表按该接入链路核定，不由普通推理可用性推断。

统一图片输入到上游参数的映射规则由对应 Provider 的媒体生成适配实现拥有，包括比例、分辨率档位与上游尺寸字段的转换；统一 `generate` 工具不维护供应商映射表，也不要求模型传入供应商专用参数。允许适配实现将请求比例和分辨率档位近似映射到上游支持的尺寸，因此 `aspect_ratio` 与 `resolution` 表达生成偏好，不构成精确输出保证。此选择取代先前讨论中的严格尺寸要求，以适应不同后端的离散尺寸能力；代价是生成图片的实际比例与像素规模可能不同于请求。该许可不等于允许静默丢弃参考图片或改变生成类型。

媒体生成沿用普通推理的可重试错误分类及 Route 重试、Target 切换策略，不因请求已发送且执行状态不明而额外禁止重试。此选择优先保持现有故障恢复行为，明确接受上游可能已经执行、因重试或切换导致重复生成及重复消耗额度的风险；它不承诺恰好执行一次，也不将所有错误、用户取消或本地 Artifact 收存失败重新归类为可重试的上游错误。已有输出提交边界继续适用，参见 [ADR-0034](0034-layer-route-target-selection.md)。

参考素材与生成产物沿用既有 Artifact 身份、Principal 归属及传输授权边界，不另建文件存储或公开下载身份。成功结果返回 `artifact_reference`、`mime_type`、以字节计量的 `size` 及类型专属的 `media`；不重复返回裸 Artifact ID。图片的 `media` 包含从实际产物读取的像素 `width`、`height`，不得以请求值代填，不再重复返回推算比例或分辨率档位。该结果使调用方能够在允许近似映射的同时识别实际产物规格；未来媒体类型的规格字段随其能力另行定义。

完整工具契约与本期范围见 [媒体生成设计](../design/media-generation.md)。本决策记录功能设计，不表示媒体生成已经实现。
