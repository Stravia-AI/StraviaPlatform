# 媒体生成绑定 Route 而非单个 Provider

媒体生成按类型由管理员绑定 Route，目前只支持图片；`generate` 按类型选择该绑定，调用方不能指定 Route。专用 Route 增加配置成本，但比固定到一个 OAuth Provider 或另维护账号列表更好：可直接复用多账号调度与故障恢复。独立生成没有对话历史，不虚构 Target Continuation 或 Affinity。

图片生成绑定要求已启用、有可执行 Target 的图片生成用途 Route。原始图片输出登记与适配器能力缺一不可；参考图还要求明确登记图片输入。模态是资格过滤，不是新的优先级。后续输出规格漂移时，保留失配配置供修复，只调度其余合格 Target；其他适配器不兼容仍明确失败。绝不丢弃参考图来换取资格，也不因关闭功能总开关而隐式解除绑定。

统一工具不暴露供应商参数；适配器可将比例与分辨率偏好近似映射到上游支持的离散尺寸，结果报告产物实际规格。素材和产物仍由现有 Artifact 身份、Principal 与传输授权管理。允许既有重试及切换策略在执行状态不明时恢复，代价是可能重复生成、重复计费；不承诺恰好一次，也不把取消或本地收存失败当作可重试上游错误。

平台总开关管执行，API Key 的透明注入选择只控制自动暴露，默认不选，避免升级后扩大已有 Key 的工具面。工具、绑定、上游接入和交付契约见[媒体生成设计](../design/media-generation.md)。
