# Vendor Plugin 携带锁定版本的 codec

四大标准 Protocol Codec 作为共享库维护，Vendor Plugin 在构建时引用并锁定版本，将所需实现编入或组合进一个自包含 Wasm 文件；四个通用协议插件遵循相同规则。安装不另行获取 codec 包，运行时不绑定宿主提供的可变 codec 实现，以确保插件的协议实现随插件发布，而不是随宿主升级隐式替换。

不采用宿主共享 codec：它可以减少插件产物重复并集中分发修复，但会引入宿主与插件行为耦合，或要求宿主维护多版本 codec。选择自包含交付，接受代码体积重复以及 codec 修复需要重新发布相关插件的成本；共享源码仍是唯一维护来源。

该决定不保证插件能在任意宿主版本上运行，宿主 Interface 兼容性必须独立校验。源码库链接与 Component composition 的具体工具方式另行选择；本 ADR 记录目标设计，不表示实现已经完成。
