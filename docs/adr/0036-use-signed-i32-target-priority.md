# Target Priority 使用有符号 32 位全区间

ADR-0034 把 Target Priority 从 1|2 放宽到 0–100000，字段类型已经是 `i32`。泳道编辑按参照值 ±1 建层，从缺省 0 向下会得到负数；再保留 100000 人工盖帽会让类型、校验和编辑手势各说各话。

因此合法范围改为 -2147483648–2147483647，缺省仍为 0，越大越优先。同值仍为同一优先级组。触及类型边界时不能再 ±1。本 ADR 只改范围；ADR-0034 的分层选择顺序不变。

## Considered options

- 维持 0–100000：与 ±1 建层和 `i32` 存储不一致，从 0 无法向下建层。
- 只放到 `0..=i32::MAX`：对齐类型上限，但禁止负数，0 以下不能建层。
