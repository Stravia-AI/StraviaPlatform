# Target Priority 使用有符号 32 位全区间

泳道编辑按参照值 ±1 建层，从缺省 0 向下会得到负数；人工封顶又会让类型、校验和编辑手势不一致。

因此合法范围改为 -2147483648–2147483647，缺省仍为 0，越大越优先。同值仍为同一优先级组。触及类型边界时不能再 ±1。仅以优先级数值分组，不改变 [ADR-0034](0034-layer-route-target-selection.md) 的分层选择顺序。

## Considered options

- 维持 0–100000：与 ±1 建层和 `i32` 存储不一致，从 0 无法向下建层。
- 只放到 `0..=i32::MAX`：对齐类型上限，但禁止负数，0 以下不能建层。
