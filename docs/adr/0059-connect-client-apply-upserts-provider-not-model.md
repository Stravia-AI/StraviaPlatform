# Connect Client Apply upserts provider, not current model

Connect Client Apply incrementally upserts the Stravia provider into the Connect Client Global Config. For Codex the provider points `model_catalog_url` at the Gateway's live `/codex/models`; Apply writes no static catalog file and removes a stale top-level `model_catalog_json`, which takes precedence over the URL and would disable live discovery. It may set a separate active-provider key so GUI clients without a provider picker actually use Stravia. It does not write the current/default model, and does not write fused provider+model keys. Claude Code is the exception: merge only Anthropic env mappings, including the four model slots. Existing files that fail to parse are left untouched. File apply lives only in Stravia Desktop; copy-paste of the same incremental preview remains available, including on the standalone server.
