# 分离 Artifact 引用与临时传输授权

Artifact Reference 保留现有 Principal 归属边界：引用本身不授予访问权，同一 Stravia API Key 对应的 Principal 可以跨对话解析，其他 Principal 不得解析。平台向客户端或 Provider 提供下载地址前必须先完成相应归属鉴权，再签发单个 Artifact 的限时 Artifact Download Grant；签名地址采用持有即授权的语义，在有效期内不要求额外 API Key。用于客户端上传的 Artifact Upload Grant 仅允许向指定 Principal 上传，不授予模型调用、读取已有文件或管理权限。

该决策允许 Provider 在不持有 Stravia API Key 的情况下抓取文件，也让客户端能使用普通下载工具；代价是签名地址可被转交，泄露后在有效期内可被他人使用。拒绝把稳定 Artifact Reference 本身作为下载凭据，也不要求每次签名下载额外携带 API Key。“文件公开访问域名”仅表示下载入口的网络可达性，不表示文件永久公开。

## 上传凭据的交付边界

上传提示词注入默认关闭。关闭时不自动插入 curl 上传说明，也不因模型输出 `<stravia-upload-key>` 而签发真实上传凭据；开启后才注入说明并执行下述交付替换。该开关不影响现有上传接口、文件自动收存或 Artifact 下载，已签发凭据的回传保护也不因关闭开关而停止。默认关闭是因为该功能会主动改写系统提示词与客户端输出，并签发上传授权，须由管理员明确启用。

开启上传提示词注入功能后，模型只接触 `<stravia-upload-key>` 占位符；平台在交付给 Connect Client 的工具调用参数与普通回答中，将该占位符替换为真实 Artifact Upload Grant。思考内容与 Platform Tool 参数均不替换。允许普通回答替换，是为了让用户能直接复制并执行回答中的上传命令；代价是模型仅解释、引用或复述占位符也可能触发凭据签发，且真实凭据可能被客户端聊天记录或工具日志保存。

## 上传凭据的历史与持久化边界

真实 Artifact Upload Grant 只在客户端交付时出现，不进入模型上下文或平台历史、日志及诊断记录；这些记录使用 `<stravia-upload-key>` 占位符。客户端回传平台签发的真实凭据时，平台必须在发送给 Provider 前恢复为占位符，已过期凭据也适用，且该保护不依赖可逆脱敏开关。历史回传本身不续期或签发新凭据；只有新的输出交付命中上述允许替换的位置时，才进行凭据替换。上传授权的校验与必要生命周期元数据不等于保存真实凭据，具体表示方式留待实现设计。

该规则对上传凭据优先于 Wire Debug Capture 的一般正文保留约定：诊断记录不得因追求 wire 原文完整性而保存真实上传凭据。

## 上传授权有效期与消费规则

Artifact Upload Grant 自签发起固定有效 15 分钟，有效期内允许上传多个文件，使用不续期。文件保留期与上传授权有效期相互独立，使用文件不能延长上传凭据的有效期。选择多文件授权而非一次性消费，是为了支持循环上传、并行上传与有效期内的客户端重试；重试不承诺自动去重。代价是凭据泄露后，持有者可在剩余有效期内反复上传，因此文件大小与容量限制仍需单独约束。

## 关闭功能与既有授权

关闭上传提示词注入只停止新增说明注入与上传凭据签发，不立即撤销已经签发的 Artifact Upload Grant；已有凭据继续有效至原定期限，使用不续期。例如 12:00 签发、12:15 到期的凭据，在 12:03 关闭功能后仍可使用至 12:15。

该选择避免客户端刚收到上传命令或正在上传时被提示词功能开关打断；代价是关闭后最多仍存在 15 分钟的既有上传授权窗口。它不授予绕过所属 Stravia API Key 禁用或撤销的资格，API Key 本身的状态控制与提示词功能开关相互独立。

## 同一响应内复用上传凭据

同一次响应中多个允许替换位置的 `<stravia-upload-key>` 复用同一个仍有效的 Artifact Upload Grant，不跨响应复用；普通回答与客户端工具调用参数采用同一规则。后续响应需要上传凭据时重新签发，自新凭据签发起固定有效 15 分钟。

如果单次响应持续到原凭据过期，后续替换时签发新凭据，不延长旧凭据，也不交付已过期的凭据。该选择避免重复占位符导致大量等价凭据，同时不让同一凭据随多轮对话持续续期；它不改变思考内容与 Platform Tool 参数不替换的边界。

本决策确认授权、交付、历史保护、上传授权有效期、功能关闭及响应内复用边界，不表示相关接口已经实现。下载地址与签名有效期见 ADR-0050，Artifact 引用的读取参数见 ADR-0051。
