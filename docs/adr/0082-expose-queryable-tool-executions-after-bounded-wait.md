# 以有界同步等待交付可查询的工具执行

## 背景与决策

公开的 `generate` 与 `StraviaRead` 采用同一有界同步等待；能及时完成就返回原工具结果，否则用 `stravia://tool-executions/<id>` 交付已持久化的执行。引用按 Principal 隔离，不授予权限；调用者用 `path` 查询，并可用 `body.wait` 请求短暂等待。查询只观察原执行，不重放、续期或接管；内置 Agent 的基础工具不暴露公开执行引用。

取消分界是后台交接的持久化提交，不是 History Marker 发布或客户端确认收到引用。交接前原调用者断开会取消本地执行；提交后原请求断开和查询取消不影响共享执行。重启中断未完成执行，不自动重放。结果按终态独立保留，不依附来源诊断或 Artifact 的寿命。

History Marker 固定本次实际交付结果（可能是执行引用），后台完成不覆盖它，也不保活原 ToolResult Hook。交接前取消获胜时封存明确取消；原 Hook 无法完成且没有确定取消时，封存交付未完成的错误，不把未经 Hook 的原始成功输出冒充已交付结果。执行终态与本次交付是两个事实。

## 权衡

始终返回任务会破坏快速结果路径，始终阻塞则占住客户端 deadline；自动交接保持兼容，但不承诺客户端断开后远端停止，也不承诺恰好一次。统一执行模块集中所有权和仲裁，工具只承担领域工作。完整等待、查询与保留见 [工具执行交接](../design/agent-core.md#工具执行交接)；隐藏历史边界见 [ADR-0028](0028-persist-hidden-history-behind-markers.md)。
