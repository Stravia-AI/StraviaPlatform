# 可逆脱敏只在本地检测凭据

Stravia 的可逆脱敏使用内置 Betterleaks 离线规则在本地识别凭据类秘密，不执行会向外部服务发送候选凭据的联网 `validate`。本地检测命中后即可替换，不以凭据真实有效为前提；这是为避免保护流程本身外传秘密而接受的误报取舍，联网验证可能降低部分误报，但会扩大秘密接收方并引入第三方审计、限流与网络失败。

本 ADR 的保护对象是模型侧凭据处理，不是诊断存储的普遍保密保证。普通 Observation 与 Debug Trace 均仅遮盖实际 HTTP `Authorization` header 值；普通观测的实时展示、落盘和导出仍可能保留下载授权及其他原始凭据。该写入策略不改变本 ADR 的检测、映射、替换和还原边界，也不放宽进程日志或普通客户端错误的脱敏。

## 已知秘密的重复出现

符合 `<!--sr:<28 位 ASCII 小写字母>-->` 完整格式的凭据标记是协议原子；它是固定长度的短 HTML 注释，不参与新凭据检测，出站精确替换也不改写其内部标识符。新标识符由密码学安全随机生成器在 `a`–`z` 中均匀采样，标识符空间约为 131.6 bit。此边界同时适用于当前 Key 的有效映射、其他 Key 或未知引用；标记能否还原仍由当前 Principal 的有效映射决定。相邻的普通文本继续正常检测与保护，避免宽泛规则对标记再次脱敏导致嵌套引用和还原失败。标记格式不改变各持久化面的过滤边界：普通 Observation 与 Debug Trace 仅遮盖实际 HTTP `Authorization` header 值；进程日志与面向客户端的普通错误仍对真正的 credential header 和结构化凭据字段执行永久脱敏。

标记不与 History Marker 共享存储、恢复逻辑或换行消费行为。它可以嵌在路径与工具参数内，不额外产生换行。模型请求存在当前 Principal 的有效引用时，平台追加一句英文系统说明，要求使用时原样保留；未知引用不授予还原权限。本次采用面向新部署和全新数据库的干净切换：迁移 0046 仍是从 `~stravia-secret:…~` 转换到旧长 HTML 注释格式的历史迁移，本次不修改；两种旧格式均不再解析或还原，也不改写 Stravia 的不可变历史或外部客户端、上游历史。不应直接复用仍依赖旧引用的数据库或会话；应另外保留旧数据库与用户数据而不是删除，再使用全新数据库并开始新对话。

可逆脱敏开启时，除扫描内置规则外，也对当前 API Key 下有效映射中的秘密原文做精确匹配；已知秘密再次出现不要求重新命中依赖字段名等上下文的规则。本次请求新识别出的秘密也覆盖本次全部受保护模型文本中的其他相同原文，不受出现先后顺序影响；不同 API Key 的映射不参与检测，过期映射不作为已知秘密来源。

每次都要求重新命中规则会让已经识别的秘密在脱离原上下文后漏出，因此不采用。此选择接受首次误报的值在映射有效期内重复出现时也被替换的代价；关闭总开关后停止此精确匹配与新增替换，已有占位符的还原仍按 ADR-0044 执行。

## 规则更新边界

Betterleaks 规则随 Stravia 版本内置和更新，运行时不下载规则，也不提供手动或定时规则更新。相较于运行时同步，此选择使同一 Stravia 版本的内置检测规则保持稳定且支持离线使用，代价是新增规则必须等待 Stravia 发布；发布时同步规则不构成允许联网验证的例外。

Betterleaks 是唯一的内置规则来源：曾补充的 Kingfisher v1.109.0 离线规则已移除，以避免两套规则并存带来的重复命中、格式更宽的误报以及额外的快照与许可维护。不按报告置信度屏蔽规则；`validate` 仅保留在原始快照中，不编译、不执行。已写入的历史命中记录不重写，已保存的映射仍可还原。

## 处理故障

可逆脱敏开启时，扫描器报错、替换失败或映射无法保存必须使本次请求显式失败，不能跳过保护后把原文发送给 Provider；如果客户端流式响应已经开始，则显式终止该流，不降级绕过保护。此选择优先保证保护边界而非故障时的请求可用性；正常扫描完成但没有命中规则不属于处理故障。
