# 可逆脱敏只在本地检测凭据

Stravia 的可逆脱敏使用内置 Betterleaks 与 Kingfisher 离线规则在本地识别凭据类秘密，不执行会向外部服务发送候选凭据的联网 `validate`。本地检测命中后即可替换，不以凭据真实有效为前提；这是为避免保护流程本身外传秘密而接受的误报取舍，联网验证可能降低部分误报，但会扩大秘密接收方并引入第三方审计、限流与网络失败。

## 已知秘密的重复出现

符合 `~stravia-secret:<32 位小写十六进制>~` 完整格式的占位符是协议原子，不参与新凭据检测，出站精确替换也不改写其内部标识符。此边界同时适用于当前 Key 的有效映射、其他 Key 或未知引用；占位符能否还原仍由当前 Principal 的有效映射决定。相邻的普通文本继续正常检测与保护，避免宽泛规则对占位符再次脱敏导致嵌套引用和还原失败。

可逆脱敏开启时，除扫描内置规则外，也对当前 API Key 下有效映射中的秘密原文做精确匹配；已知秘密再次出现不要求重新命中依赖字段名等上下文的规则。本次请求新识别出的秘密也覆盖本次全部受保护模型文本中的其他相同原文，不受出现先后顺序影响；不同 API Key 的映射不参与检测，过期映射不作为已知秘密来源。

每次都要求重新命中规则会让已经识别的秘密在脱离原上下文后漏出，因此不采用。此选择接受首次误报的值在映射有效期内重复出现时也被替换的代价；关闭总开关后停止此精确匹配与新增替换，已有占位符的还原仍按 ADR-0044 执行。

## 规则更新边界

Betterleaks 规则与补充的 Kingfisher v1.109.0 离线规则随 Stravia 版本内置和更新，运行时不下载规则，也不提供手动或定时规则更新。相较于运行时同步，此选择使同一 Stravia 版本的内置检测规则保持稳定且支持离线使用，代价是新增规则必须等待 Stravia 发布；发布时同步规则不构成允许联网验证的例外。

Kingfisher 的补充快照仅保留检测字段，不包含联网验证、吊销或网络请求模板。正则、捕获组选择、熵阈值、字符要求、排除子串及本地校验和参加检测；隐藏的用户名、主机名等辅助规则不单独保护。`depends_on_rule` 在上游用于绑定联网验证参数，不转为离线检测的必需条件。与现有 Betterleaks 一致，不按报告置信度屏蔽规则；两组规则的过滤及包含关系抑制相互隔离，共享凭据去重与替换边界。此扩展接受较宽格式规则带来的误报，不将格式命中当作厂商归属或有效性证明。

## 处理故障

可逆脱敏开启时，扫描器报错、替换失败或映射无法保存必须使本次请求显式失败，不能跳过保护后把原文发送给 Provider；如果客户端流式响应已经开始，则显式终止该流，不降级绕过保护。此选择优先保证保护边界而非故障时的请求可用性；正常扫描完成但没有命中规则不属于处理故障。
