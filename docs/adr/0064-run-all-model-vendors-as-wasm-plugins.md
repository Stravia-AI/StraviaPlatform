# 所有模型 Vendor 统一使用 Wasm 插件

Stravia 最终将所有模型 Vendor，包括随程序预置的供应商与四个通用协议 Vendor，统一为 Wasm 插件；预置与本地安装只区别分发来源，不区别能力契约或执行通道。预置包直接随程序交付，在插件管理页面展示并支持本地包更新，不要求用户首次使用前逐个安装。

不长期保留“内置原生、外部 Wasm”的双通道：双通道可以减少初期迁移，但容易使复杂认证、自定义协议与管理能力仅在内置实现可用，并持续产生行为差异。统一机制要求完整迁移现有供应商、验证特殊认证与流式语义并测量运行成本，以换取一套可覆盖真实供应商的插件契约。

宿主继续拥有通用网络、存储、授权、调度和客户端协议处理；该决定不将整个网关移入 Wasm，也不把重试或 failover 策略交给供应商。此处只确认目标架构，不表示迁移已经完成；宿主升级时如何处理预置插件版本另行决策。
