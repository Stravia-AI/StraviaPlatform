# 按规则开关与强度分层管理凭据保护，并按最近检出回收映射

上下文检测不能识别后续孤立出现的裸 token，因此保留按 Principal 隔离的字面映射，而不是只在检测时替换。反过来，一律按子串替换会让短秘密误伤普通词。强秘密按子串匹配，弱秘密要求 ASCII 单词边界，自定义简易规则的检测、替换和观测遮罩共用相同判定。强度不是有效性验证；弱值紧贴单词字符时仍可能漏匹配，这是减少误伤的取舍。

禁用规则不应只阻止新命中：没有现行启用归因的映射也停止出站替换及管理面遮罩，但旧占位符仍可还原，[ADR-0087](0087-list-credential-hits-per-mapping-with-retained-item-context.md) 的复用记录与命中定位也保持可查。规则变更改变 Provider 可见历史，只有完全相同的前缀仍可续接，无需额外失效机制。禁用不是撤销凭据，也不删除映射。

首次发布时间无法刻画跨对话复用。用历史保留窗加节流余量判断最近检出是否过期，只有规则再次真实检出才续期，避免替换、还原或管理面查看无限延长明文的本地保存时间。过期即停止替换和遮罩；Turn 引用只保护历史还原，不保护出站复用。后台回收未被引用的过期映射；未知旧标记原样透传。过期或禁用后，规则无法重新识别的裸值可能原样出站。

一次性退役归因清理是有意的例外：完全没有现行归因的旧映射解除引用后删除，牺牲这些标记的可还原性，以清除退役规则遗留的错误替换；混合归因只清除退役项。规则、匹配、过期及迁移契约见[凭据保护设计](../design/credential-protection.md)。
