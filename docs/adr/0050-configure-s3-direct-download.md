# 允许通过开关选择 S3 直连下载

Artifact 上传与引用接口保持统一，下载交付允许使用存储后端的原生签名地址。仅设一个“外部签名下载”开关，同时决定 Provider 的文件交付方式与 StraviaRead 返回给客户端的下载去向，不再另设 S3 直连开关。下载方式不改变 Artifact 的归属边界。

统一开关默认关闭，配置 S3 不自动启用。关闭时客户端下载经平台签名链接，Provider 使用内联文件内容；开启时，内部存储使用平台签名地址，S3 使用后端原生预签名地址、不经平台重定向。Provider 交付仍受协议表达能力约束，不能表达所需输入就明确失败。开启直连节省平台带宽，代价是下载方必须能直达公开入口或 S3；不要求存储桶公开，也不独立提供“Provider 内联、客户端 S3 直连”的组合。

生成链接使用管理员保存的完整入口，不随请求的 Host 动态改变。地址必须按实际入口签名，不能在签名后替换域名。下载链接默认 15 分钟，每次上游发送时至少剩余 5 分钟，S3 签名凭据的期限也计入判断。详见 [Agent Core](../design/agent-core.md) 的 Artifact 交付规则。
