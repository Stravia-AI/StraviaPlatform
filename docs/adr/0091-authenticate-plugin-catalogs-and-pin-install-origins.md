# 验证插件目录并固定实际安装来源

Vendor Plugin 通过公开 GitHub 仓库的签名目录分发，宿主固定数字仓库身份和独立 Minisign 公钥。官方信任根随宿主构建提供，第三方首次添加由管理员确认完整指纹；后续换钥必须重新确认。目录签名绑定仓库、Release 和压缩产物及 Component 的摘要，下载通道与镜像不成为信任根。

每次安装保存实际来源快照，更新只跟随该来源。同一 Vendor 不并行安装多个来源；换源、降级、凭据继承与数据丢弃继续通过完整影响预览确认。提交使用预览时验证过的同一字节，并在安装事务内校验来源信任修订及已见版本冲突。移除或停用来源不卸载已安装插件，也不撤销既有连接。

这是对 [ADR-0068](0068-trust-vendor-plugins-with-connection-credentials.md)的补充，不改变连接范围的凭据授权。自动检查更新不自动安装新代码；内嵌 `base` 的既有宿主更新规则不扩展到市场。签名证明发布来源，不证明代码安全或目录最新；第三方首次信任仍依赖当前网络路径，应通过独立渠道核对指纹。

选择独立 Minisign 签名而非仅信任 HTTPS/SHA256SUMS，使国内镜像与 GitHub 直连共享同一验证边界；不复用 Desktop updater 密钥，避免不同发布面的密钥权限耦合。分发采用已有依赖支持的单 frame Zstd，限制窗口和解压大小；不为更小的 XZ 产物增加另一套安装解码路径。具体契约见[插件市场设计](../design/plugin-marketplace.md)。
