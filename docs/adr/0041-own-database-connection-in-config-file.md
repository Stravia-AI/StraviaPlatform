# 数据库连接仅由配置文件定义

首次设置向导需要保存下一次启动仍能使用的数据库连接。本次设计选择配置文件作为数据库连接的唯一来源，移除现有数据库 CLI 参数及环境变量入口，而不采用 CLI、环境变量与文件的分层覆盖；这避免向导保存值与实际生效值存在两套解释。

该决定要求 Docker、Nix 和启动脚本同步迁移，已有 PostgreSQL 安装需先将原连接信息迁入文件，不能在配置缺失时默认切换到 SQLite。配置损坏或数据库不可达必须显式失败；目标数据库是否存在管理员决定首次设置是否完成，不另存本地完成标志。详细契约见 [管理用户与首次初始化设计](../design/admin-auth-bootstrap.md)。

这是已确认的目标设计，不表示代码与部署入口已经完成切换。
