# 控制台对话

控制台对话是管理面 `/` 的第一方图文对话入口，Server 与 Desktop 共用 WebUI。它直接调用既有 `POST /v1/responses`，不增加后端聊天 API、管理推理身份或服务端聊天存储。产品边界见 [ADR 0079](../adr/0079-keep-console-chat-history-in-the-admin-client.md)；界面规范见 [DESIGN.md](../../DESIGN.md)。

## 使用与身份

完成服务、模型与 API Key 配置后，在「对话」选择 Key，并从输入区底部的模型／推理强度组合入口发送消息。输入区始终停靠底部；上方仅显示 Key 选择或固定归属，标题菜单提供重命名与删除。唯一候选自动选择；多个候选优先复用仍有效的上次选择，否则要求手动选择。模型展示友好名称，调用仍使用 Route 的模型 ID。组合面板分层选择模型和强度；只对已公布且具有规范顺序的档位使用离散滑杆，不虚构五档或模型家族。

回答下方记录实际发送的客户端模型 ID、强度和时间。所有请求都要求 `reasoning.summary: "auto"`，以获取可读摘要。「默认」有已配置的 Route 默认强度时显式发送该档位，否则不发送 `reasoning.effort`；这是因为摘要本身已经构成推理指令，不能依赖 Core 的无指令默认值规则。显式选择只能来自模型登记的支持档位；`off` 在 Responses wire 上写作 `none`。

第一条消息将对话固定归属到所选 Key。之后不能替换其身份，但每次发送可以更换该 Key 允许的模型和推理强度。模型删除、停用或取消绑定后要求重新选择模型；Key 删除、停用或过期则使整个对话只读。已知到期时间在本地定时器边界重新判定，不轮询目录；目录初次读取失败是未知状态，不冒充 Key 已删除。只读历史仍能阅读、复制、重命名和删除；「用其他 Key 新建对话」不会迁移旧消息或修改旧归属。

推理请求的唯一认证是所选 Key 的 `Authorization: Bearer …`，不附带管理 Cookie。Key 明文只在实际发送时通过现有管理 API 临时读取，不进入聊天控制器、IndexedDB、地址栏或偏好。管理登录失效时先恢复登录，再重新读取目录和 Key；已经发出的 Key 认证流不因管理页面跳转而停止。文字与图片会发往所选模型的上游服务；Core 沿用 Artifact 收存、归属与保留，显式 Wire Debug 仍可能保留媒体原始内容。不能把本地历史误认为离线推理或数据不出设备。

## 图片输入

图片「＋」、粘贴与拖入共用附件草稿，支持多图预览和逐张移除，仅接受 PNG、JPEG、WebP 原图，不裁剪、压缩或生成替代摘要。每次发送仍要求非空文字，不能发送纯图片。当前草稿或完整历史包含图片时，必须满足所选 Route 的 `supports_image_input`；不兼容则提示手动换模型，不自动切换、不删除图片、不扩大 Key 的允许范围。文件读取、收存、持久化或上游拒绝均明确报错，文字与图片草稿保留。

用户消息以独立 `images` 字段保存原始 data URL 及文件名等元数据；请求用 Responses `input_text` / `input_image` parts，不将附件编码混入普通文字，也不保存临时 object URL 或远端过期引用。刷新、完整多轮回放、重试与重新生成使用同一原图。图片嵌入既有对话记录，无需新增 IndexedDB 版本或后端 schema；删除对话一并删除本地图片，但不改变 Core Artifact 留存。发送前本地保存失败不会启动模型调用，未保存的轮次会回滚并保留草稿。

## 回答与恢复

- 正文、推理摘要及可读推理原文按 Responses 流增量展示。思考按公开 reasoning item 身份和顺序独立展示，优先摘要、无摘要才回退可读原文；无可读内容不占位。最新进行中思考自动展开并显示「正在思考」与忙碌语义；同段手动收起后不因增量重开。item 正常完成、停止或失败时停止转圈并收起一次，后续人工展开保持不变。停止与失败保留已收到正文和思考，终态 output 仍是权威历史，不与临时 delta 重复拼接。
- 对话与请求观测复用同一消息框架：助手正文平铺，用户靠右使用低对比度气泡；数据模型与展开策略不合并。
- 正文及展开思考复用安全 Markdown，支持 GFM、Mermaid 声明代码块与 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 公式。库、样式和字体随应用打包并按需加载，不使用 CDN。流式片段完整后才渲染；不完整内容保留源码，最终无效内容保留源码和可恢复说明。普通 HTML 仍转义；Mermaid 配置、脚本、交互、HTML、外部媒体与 TeX 受信任扩展不进入只读展示。工具结果不递归当作 Markdown。
- 普通 HTML 注释不展示、不复制；客户端不解码、不重建 Core 私有历史封装，也不把签名、密文、工具或占位符解释成可读思考。
- 「输入」展示净输入：仅当 Responses 终态的 `usage.input_tokens` 与 `usage.input_tokens_details.cached_tokens` 均已报告时，计算 `max(总输入 - 缓存读取, 0)`；缓存写入不参与扣减。输出直接使用已报告的 `output_tokens`，不再次累加思考。任一输入操作数未知时不显示输入数值，缺失不补零、不估算；失败与停止不伪造用量。客户端协议中的总输入保持不变。
- Stop 中止该对话的 fetch 并保留已展示文本；它不会停止其他对话。刷新会中断网络，最近持久化的增量以 stopped 状态恢复，不依赖卸载时的异步写入。
- 失败显示真实错误与「重试」。重试复用失败轮次的请求模型、强度和输入，不再次追加用户消息；原模型不可用时禁用重试并提示选择其他模型重新生成。「重新生成」替换最后一条助手回答，使用当前选择并重建此前历史。两种操作都遵守当前 Key 与模型可用性。Refusal 正文同样可流式显示、复制、搜索并原样回放。
- 配置读取失败提供刷新恢复；本地读取或写入失败显示错误，不冒充空历史或已保存。推理失败不清除此前已完成轮次。

## 历史与 Responses 回放

每个请求使用完整多轮 `input`；不使用 `previous_response_id`。已完成或不完整响应的权威来源是终态返回的 `response.output`，客户端保存原始 output item 顺序，并在下一轮按原样回放 reasoning、message 等 items；不只回放可见正文，不替换私有 history marker，不自行修补孤立工具对。

当前输入依次包含此前用户消息、此前 completed／incomplete 的原始 output items，以及本轮用户消息。失败助手不进入下轮输入；stopped 的部分回答按普通 assistant 文本回放，不制造 reasoning 或工具 item。流式显示与最终持久化内容的切换以终态 output 为准，不拼接临时 delta 与终态造成重复。

如果 Key 启用了透明工具注入，Core 仍按原有规则执行平台工具并可能产生额外费用，聊天客户端透明保存与回放服务端返回的历史封装。UI 不提供独立工具调用面板，不解包内部工具轨迹。History Marker 过期或不属于当前 Principal 时，Core 会静默省略对应隐藏历史而不报错：旧对话仍可发送、可见回答仍在历史中，但模型不再看到当时的隐藏推理与平台工具原始结果。客户端不复制保留期规则。排查底层调用继续使用「请求记录」。

## 浏览器本地存储

历史使用 origin 作用域的 IndexedDB `stravia-console-chat`：`conversations` 保存对话 ID、标题、Key ID／名称快照、模型与强度选择、创建／活动时间和消息；`preferences` 只保存上次选择的 Key ID 与模型 ID。没有 Key 明文、管理令牌或服务端消息副本。生成状态留在根布局单例内存中；持久化的中间检查点已经是可恢复的 stopped 状态。

本地存储版本 2 的消息 `usage.inputTokens` 保存净输入，不在显示时重复扣减。版本 1 只保存总输入，未保存缓存读取，升级时在同一 IndexedDB 事务中移除旧消息的输入计量，使其保持未知；正文、思考、原始 output items、输出用量、对话归属和选择偏好全部保留。升级失败显式报错并回滚，不展示未完成迁移的历史。

这不是加密存储。对话内容、原始图片、推理与原始 output items 可被同一浏览器配置及 origin 的脚本访问；共享设备、恶意扩展和 XSS 仍有内容泄露风险。换浏览器配置、换域名／端口、清除站点数据或卸载 WebView 都可能使历史不可见或丢失。Server 与 Desktop 不同步历史，不提供导入、导出、服务端备份、跨设备或跨窗口实时协作。Web 和 Desktop 的不同 origin 使用各自独立存储。

侧栏只显示最近活动的 5 个对话；超过 5 个时进入「全部对话」。历史页搜索标题与可读正文，支持重命名、单条删除和清除全部。删除或清除会先终止相关生成，随后删除本地记录，晚到的流事件与编辑不能复活历史；存储删除失败保留历史和可重试确认，不显示删除成功。重命名成功后才发布新标题，流式检查点只保存已提交标题，失败保持原标题。清除确认显示本浏览器的总对话数量且不可恢复。清除历史保留不含秘密的选择偏好。

## 导航与配置

`/?conversation=<本地 ID>` 是本浏览器的选择地址，不是可共享的服务端资源链接。刷新、前进和后退恢复选择；未知 ID 显示「对话不存在」及新建入口，不发送请求。切换管理页面不会销毁根布局的控制器或停止生成，可同时让不同对话继续生成；同一对话只能有一个进行中的请求。阅读者离开底部后暂停自动跟随，提供回到最新内容按钮。

初次配置按顺序引导：无服务、服务全部停用、无模型、无可请求模型、无 Key、无可用 Key。无可请求模型包括未启用或没有指向已启用服务的已启用 Target。引导替代输入框，只链接到既有服务／模型／Key 配置页面；返回对话时重新校验目录。Desktop 端口回退提示保留在对话顶部。

原 Overview 仪表盘和 Request Spine 已移除。监控数据仍在「用量分析」，接入第三方客户端仍在「接入客户端」；新对话不复制这些管理表面。

## 验证边界

- 控制器 seam：内存存储、受控流与目录端口测试身份、候选、完整回放、错误、停止、刷新恢复、并发与删除竞态；不依赖真实网络或 IndexedDB。
- Chromium seam：真实页面、真实 IndexedDB 与受控 Responses 流，覆盖安全渲染、复制、导航、历史管理、只读恢复、配置引导、管理登录恢复、中文移动端和键盘选择。
- 产品 seam：隔离的 SQLite Server 与 loopback 假上游，管理 API 创建实际服务／模型／Key，真实两轮请求验证 Key 身份及 reasoning/output 回放；不调用生产服务。
