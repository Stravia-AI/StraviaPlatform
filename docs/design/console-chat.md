# 控制台对话

控制台对话是 Server 与 Desktop 管理 WebUI 的图文入口，直接调用 Gateway 的 `POST /v1/responses`。
它不添加管理推理身份、后端聊天 API 或服务端聊天存储，也不是平台 Session。见 [ADR-0079](../adr/0079-keep-console-chat-history-in-the-admin-client.md)。

## 身份与执行

- 首条消息固定 API Key 实体及其 Principal；不能更换原对话归属。每次发送可选择该 Key 当前允许的 `inference` Route 与已声明强度。
- 模型已删除、停用或取消绑定时要求重选；Key 删除、停用或过期时对话只读，仍可阅读、复制、重命名和删除。目录读取失败不冒充 Key 已删除。
- 请求只用 Key 的 Bearer 认证，不附带管理 Cookie。明文 Key 仅发送时经管理 API 临时取得，不进入聊天状态、持久化或 URL；管理认证恢复后重新读取目录与凭据，不终止已发出的 Key 认证流。
- 请求使用客户端 Route 模型 ID，并发送 `reasoning.summary: "auto"`。选「默认」时，有 Route 默认强度则显式发送，否则省略 effort；显式 `off` 在 Responses wire 上写作 `none`。
- 平台工具与费用沿用该 Key 的[能力门禁与透明注入](agent-core.md#平台能力门禁与透明注入)和[计费规则](cost-and-billing.md)。对话不另设工具面板，也不解析平台隐藏历史；诊断使用[请求记录](interaction-observation.md)。
- 对话缺少可用 Provider、模型或 Key 时引导到现有管理入口，不为发送或重试自动扩大授权或改绑模型。

组合选择器显示模型友好名与真实可用档位，不虚构模型家族或强度。唯一候选自动选择；多个候选仅复用仍有效的选择，否则要求手动选择。
回答下方保留实际发送的模型、强度与时间，不把后来更改的默认档位回填历史。

## 图片输入

- 附件接受 PNG、JPEG、WebP 原图，支持多张；每次发送仍须有文字。有图的草稿或历史只允许选择声明图片输入能力的 Route，不自动切换模型或丢图。
- 本地保留原图，请求使用 Responses `input_text` / `input_image`，重放与重试使用同一内容，不依赖临时本地 URL。
- Core 按 [Artifact 契约](agent-core.md#artifact-与单请求上传)收存和授权，并按 Key 的透明注入规则为上游构造附件引用。删除本地对话不缩短 Core 留存。
- 正文仅预览完整 `client_base_url` 同源、同部署前缀的 Artifact 下载授权图片；不加载任意外部 Markdown 图片。过期只提示，不自动续签或重新生成。

图片写入失败保留草稿，不把读取或上游拒绝说成成功。
发送后仍可编辑下一条草稿；本轮失败且没有新草稿时回填本轮文字与原图。

## 流式展示与历史重放

- 遵循 [Open Responses 契约](open-responses.md)。每轮发送完整多轮 `input`，不用 `previous_response_id`；已完成或不完整响应以终态 `response.output` 为准，按原顺序保存与回放原始 items，不拼接重复 delta 或重建私有 Marker。
- 正文、可读思考和拒绝正文按实际输出顺序展示；没有可读文本的思考不占位，不解码签名或密文。终态前的局部顺序与已观察时长随本地检查点恢复，不推算缺失事实。
- 每个对话最多一个进行中的请求，切换管理页面或对话不停止其他流。Stop 只中止当前对话的 fetch，保留已收到内容；刷新中断后从最近持久化检查点恢复为 stopped，不等待卸载写入。
- stopped 的可见部分只按 assistant 文本回放；失败助手不进入下一轮输入。重试复用失败轮的模型、强度和输入，不追加用户消息；重新生成最后一轮使用当前选择。编辑并重发保留该消息图片、截掉后续轮次，不保留分支。
- 流式结束后才显示上游明确报告的用量；净输入只在总输入与缓存读都已知时计算。失败终态若有用量照常展示；手动停止没有终态用量，缺失不补零。
- 安全渲染不执行 HTML、脚本、交互图表或工具输出；向上翻阅暂停自动跟随，选择「跳至最新消息」可恢复。

上游失败保留真实错误和此前已保存历史；原模型已不可用时，不自动以另一模型代替「重试」，可显式选择其他模型后重新生成。
客户端原样回放可用 Marker。若平台已独立回收隐藏历史，仍能阅读与发送本地可见历史，不由客户端重建隐藏思考或工具结果。

## 浏览器与 Desktop 本地存储

历史、图片、模型输出、检查点与选择偏好只保存于当前浏览器配置或 Desktop WebView 的 origin 作用域；不保存 Key 明文或管理令牌。
更换域名、端口、浏览器配置或 WebView、清除站点数据都可能使历史不可见或丢失。Server 与 Desktop 不同步，也不提供服务端备份或跨设备共享。

- `/?conversation=<本地 ID>` 只定位当前存储中的记录，不是可分享的服务端资源地址。不存在的 ID 不发推理请求。
- 局部或完整历史的读取、写入、删除失败均显式显示；发送前保存失败不启动调用，恢复草稿或编辑前历史。
- 删除单条或清除全部先停止相关生成，再删除记录；晚到的流事件不能复活已删历史。清除仍保留不含秘密的选择偏好。
- 历史可按标题和可读正文搜索。重命名只在本地提交成功后生效；复制或删除只读历史不改变原 Key 绑定。
- 浏览器的刷新、前进和后退恢复本地选择；不同窗口不提供实时协作。
- 本地历史未加密，同源脚本、浏览器扩展与共享设备均可能接触内容。模型请求仍把文字和图片发往上游；本地存储不等于离线推理，也不改变服务端[观测与 Debug](interaction-observation.md#wire-debug-与脱敏边界)的保留范围。
