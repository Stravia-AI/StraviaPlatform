# 中文搜索引擎接入优先级调研

| 项 | 值 |
|---|---|
| 研究日期 | 2026-08-21 |
| 范围 | `stravia-web-access` 的零凭据 HTML 搜索 fan-out；不评估需要新增持久化配置、付费合同或授权 OAuth 的 Web Provider。 |
| 已有引擎 | Google、Bing、Brave 默认启用；Baidu、360 搜索和搜狗微信已实现但默认关闭。 |

> 结论区分已由第一方页面直接观察到的事实和工程判断。HTML 页面可抓取不代表它是稳定或获准的 API；部署方仍须审查上游条款、robots、地域合规与访问频率。

## 结论

**360 搜索已按本调研接入为 opt-in；搜狗网页的中文增量更高，但只能作为后续实验性 opt-in。搜狗微信已作为独立的 opt-in 垂直来源接入。**

- 360 搜索的当前自然结果包含可直接使用的 `data-mdurl` 目标 URL；实现不需要逆向其跟踪跳转，能沿用现有 `ParseOpts` 模式。它与现有通用引擎重叠较高，仍应低权重 opt-in。[S4]
- 搜狗网页的当前结果页服务端返回标题、摘要和结果内容，同时提供微信、知乎、视频等中文生态垂直入口，和现有 Baidu/Google/Bing/Brave 相比有明确的中文内容增量；但同一入口也会触发官方验证码，并且标题 URL 是不透明的跟踪跳转。[S1][S2]
- 搜狗微信、头条与知乎的价值来自垂直内容，不能当作稳定的通用网页引擎。它们应是有独立开关、严格限流的 post-search/vertical engine；知乎还需要正式凭据。[S3][S6][S7]
- 不接入小红书的零凭据 HTML 搜索，也不把神马作为通用引擎。前者当前结果依赖客户端渲染；后者是移动结果页，广告/聚合占比高且与 Baidu/夸克内容重叠。[S8][S9]

## 推荐实施顺序

### 1. 360 搜索：已实现、opt-in

| 维度 | 结论 |
|---|---|
| HTML 入口 | `GET https://www.so.com/s?q=<query>`；当前可返回服务端 HTML 搜索结果。[S4] |
| 解析边界 | 自然结果可选 `.res-list`，标题为 `h3.res-title`，摘要为 `p.res-desc`；标题链接的 `href` 是 `https://www.so.com/link?...`，但 `data-mdurl` 提供目标 URL，因此可用手写 `href` 解析而无需逆向令牌。 |
| API 选项 | 360 智搜文档给出需要 Bearer 凭据的 `mwebsearch` 接口；这属于未来的凭据型 adapter，不是当前零凭据 HTML 引擎的替代。[S5] |
| 当前状态 | 已作为 `"360"` 引擎默认禁用、权重 `0.75` 接入；解析器使用 `data-mdurl`，测试覆盖自然结果与跟踪 URL 分离。初始 HTTP 响应未出现结果标记时，使用浏览器预访问主页后重试渲染。 |
| 风险 | 同 Baidu/Bing/Google/Brave 的通用结果重叠较高；HTML 抓取会受反自动化、地域和页面改版影响。 |

### 2. 搜狗网页搜索：高增量、实验性 opt-in

| 维度 | 结论 |
|---|---|
| 入口 | `GET https://www.sogou.com/web?query=<query>`。[S1] |
| 当前页面形态 | 已实测返回完整 HTML，包含自然结果标题、摘要与来源信息；页面同时混入 AI、翻译、百科、视频等模块，解析器必须只选择自然网页结果。[S1] |
| URL 边界 | 标题链接使用 `/link?url=...` 跟踪跳转。实现不能猜测或逆向该值；必须从页面提供的来源 URL 提取可用目标，或明确跳过无法恢复目标 URL 的结果。 |
| 建议 | 新增 `sogou.rs`，默认禁用，初始权重不高于 `1.0`；以真实页面 fixture 覆盖自然结果、AI/翻译卡片、百科卡片和跟踪链接。 |
| 风险 | 搜狗网页的官方反自动化页会要求验证码确认请求不是自动程序；未发现可替代页面抓取的通用网页搜索 API。因此可解析不等于稳定，应把 403、验证码和空结果视为单引擎失败。[S2] |

## 仅作垂直来源

| 来源 | 合理定位 | 接入边界 |
|---|---|---|
| 搜狗微信 | 公众号文章检索；新闻、行业资讯、中文技术社区的补充。 | 已作为 `sogou_weixin` opt-in 引擎接入；只收录从搜狗跳转页提取出的 `mp.weixin.qq.com/s` 直接文章链接，不返回含 token 的搜狗跟踪 URL。初始 HTTP 响应没有文章结果标记时，浏览器预访问搜狗微信主页后重试渲染。官方反自动化页面仍可能要求验证码，不能进默认并发 fan-out。[S3] |
| 头条搜索 | 新闻、视频与内容平台垂直检索。 | 当前原始 HTML 只有应用壳，结果依赖带 Argus 令牌的内部 AJAX；除非采用授权 API 或真实浏览器，不能接入现有纯 HTTP 解析器。即使未来可接，也只能是独立 vertical/post-search。[S7] |
| 知乎 | 问答与中文技术讨论的凭据型垂直检索。 | 官方开发者文档的全网/知乎搜索 API 需要授权；无凭据调用不会构成可用的零凭据引擎。[S6] |
| 神马 | 移动中国场景的最后备选。 | `m.sm.cn` 当前会跳转到验证码挑战页；另一移动入口偶发 SSR，但依赖未公开的内部端点。官方站长能力是收录提交，不是通用搜索 API。默认不接入。[S9] |

## 不建议零凭据接入

- **小红书搜索**：当前官方搜索页只返回应用壳，结果由客户端加载；没有确认到可用于本项目的公开网页搜索 API。浏览器渲染也无法消除授权、风控和稳定性问题，因此不应为此新增浏览器依赖或绕过访问控制。[S8]
- **“非官方 API”**：未获得第一方 API 文档和授权的接口不可作为实现依据；不能通过猜测签名、解密跟踪参数、模拟登录或规避验证码来补足能力。

## 实施守则

1. 新增通用来源一律默认禁用；当前排名按最终 URL 合并、叠加 engine score，直接默认开启会放大重复内容。[S10]
2. 解析器只提交可验证的最终目标 URL；不保留上游跟踪 URL，也不解密或猜测加密跳转参数。
3. 每个引擎同时加入：当前页面 fixture、自然结果选择器测试、无目标 URL 跳过测试、挑战页/空页测试。
4. 将 HTTP 403、验证码、重定向失败和空结果视为单引擎失败；不得引入登录、验证码处理、盲重试或规避反自动化的实现。
5. `SearchQuery.allowed_domains` 使用经校验的 hostname；通用引擎将其映射为 `site:` 查询条件以尽量缩小上游结果，并在解析最终 URL 后强制按域名及其子域过滤。上游忽略或误解 `site:` 时不得泄露域外结果。
